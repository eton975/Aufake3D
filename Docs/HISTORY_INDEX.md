# Documentation archive — history, not current instructions

**Current users should start at [Docs/README.md](README.md).** The files here preserve development decisions and older tests; their build commands, version labels, hash baselines and compatibility claims may be superseded.

| Historical material | Location |
|---|---|
| Original v0.8.x / v0.9.x release notes | [Release_Notes/](History/Release_Notes/) |
| Superseded installation and build guides | [Superseded_Guides/](History/Superseded_Guides/) |
| Early engine README, changelog and hotfix investigations | [Engine_Notes/](History/Engine_Notes/) |

The main repository changelog is now [CHANGELOG.md](../CHANGELOG.md). It summarises the progression without demanding that users read dozens of old files. Historical material is retained byte-for-byte where possible, and **should not be used as current installation instructions**. The current **built binaries and ZIPs are in `dist/`** after building; they are not supplied by source-code history archives.

# Historical development material

**This folder is not an installation or build guide.** `Engine_Notes/` holds
67 original, version-specific engine documentation files that were previously
mixed into the live `Source/Engine/` directory. They describe v0.1–v0.7-era
research and may mention obsolete paths, disabled or missing features, old
buffering defaults and retired DLL build procedures. Their content has been
retained for engineering provenance, **not** silently updated to v0.8.14-RC1.

Current documentation begins at [`DEVELOPER_INDEX.md`](DEVELOPER_INDEX.md),
[`SOURCE_ARCHITECTURE.md`](SOURCE_ARCHITECTURE.md), and the repository's
`BUILDING.md`. Earlier v0.8.12/v0.8.13 change notes in this documentation
folder are also historical. Retain them when citing past test evidence.
